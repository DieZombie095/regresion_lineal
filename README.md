# Regresión lineal: progresión de la diabetes

Notebook para entrenar y evaluar un modelo de regresión lineal con el conjunto Diabetes incluido en scikit-learn.

## Archivo

- `1_regresion_lineal_diabetes.ipynb`: exploración de los datos, separación de entrenamiento y prueba, entrenamiento del modelo, métricas y gráfica de evaluación.
- `evaluacion_modelo.svg`: gráfica con ejemplos de predicciones y métricas del modelo.

## Requisitos

Python 3.8 o superior. Instala las dependencias con:

```bash
pip install -r requirements.txt
```

## Ejecutar

Inicia Jupyter Lab:

```bash
jupyter lab
```

Abre `1_regresion_lineal_diabetes.ipynb` y selecciona **Run All** para ejecutar todas las celdas.

El conjunto de datos se carga directamente desde `sklearn.datasets`, por lo que no es necesario descargar archivos externos.
